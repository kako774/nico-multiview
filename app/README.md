# ニコ生マルチビュー

ニコニコ生放送を複数枠まとめて同時視聴するデスクトップアプリです。

## 起動方法(Windows)
1. [Node.js](https://nodejs.org/) (LTS) をインストール(初回のみ)
2. このフォルダの `start.bat` をダブルクリック(初回は自動でセットアップします)

## 使い方
- 上の入力欄に `lv123456789` または放送URLを貼って「追加」(複数まとめて貼付OK、最大12枠)
- 配置: 自動グリッド / メイン+サブ / 横一列 / 縦一列
- 音声は「🔇」を押した1枠だけ出ます(他の枠は自動で消音)。「全て消音」で全部ミュート
- ラベル(lv番号)をドラッグで並べ替え、「メインにする」で先頭の大きい枠へ
- ログインは、どれか1枠のページ上でニコニコにログインすれば全枠で共有・保存されます
- 並びと配置は、次回起動時も保たれます

## exeにしたい場合
`npm install` のあと `npm run dist` で、持ち運べる単体exe(portable)が `dist` フォルダにできます。
